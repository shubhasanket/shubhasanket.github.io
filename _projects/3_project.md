In this project I implemented deep learning forecasters for financial volatility, using inputs such as realized volatility, daily returns and other market-derived features.

I built a symbol-aware time-series pipeline on the *Oxford–Man Realized Volatility* dataset, which keeps each financial instrument distinct while still allowing the model to learn shared structure across symbols. Models were evaluated using mean squared error (MSE), the QLIKE loss, and directional accuracy.

*Period&#58;* November 2025 – January 2026.
