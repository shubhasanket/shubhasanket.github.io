This project implemented the *Auto-Encoder with Regression* framework for time series anomaly detection in PyTorch. The core idea is to combine reconstruction-based anomaly detection (via an auto-encoder) with a regression head on top of latent representations, which improves sensitivity to subtle anomalies in time series data.

I extended the post-processing pipeline with alternative thresholding strategies, and ensured compatibility with recent Python versions — in contrast to the TensorFlow-based *orion-ml* reference implementation.
